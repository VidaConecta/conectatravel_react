# ✈️ ConectaTravel

Sistema de gerenciamento de seguros de viagem, desenvolvido para facilitar o cadastro e o acompanhamento de clientes e apólices de forma simples, centralizada e segura.

Ideal para estudantes de tecnologia e nômades digitais que buscam viajar com mais tranquilidade.

## 📋 Sobre o projeto

O ConectaTravel permite que a equipe gerencie toda a jornada do cliente em um só lugar:

- Cadastro, consulta, edição e exclusão de **clientes**
- Cadastro, consulta, edição e exclusão de **apólices** de seguro viagem
- Vínculo entre clientes e suas respectivas apólices
- Navegação simples entre as áreas do sistema (Início, Clientes, Apólices, Introdução e Sobre)

## 🚀 Tecnologias utilizadas

- [React](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [React Router DOM](https://reactrouter.com/)
- [Phosphor Icons](https://phosphoricons.com/)

## 📁 Estrutura do projeto

```
src/
├── assets/          # Imagens e arquivos estáticos
├── components/      # Componentes reutilizáveis (Navbar, Footer, etc.)
├── models/          # Tipagens/interfaces do projeto
├── pages/           # Páginas da aplicação (Home, Introdução, Sobre, Clientes, Apólices)
├── services/        # Comunicação com a API (Cliente, Apólice)
├── App.tsx
└── main.tsx
```

## ⚙️ Como executar o projeto

Pré-requisitos: ter o [Node.js](https://nodejs.org/) instalado.

```bash
# Clone o repositório
git clone https://github.com/VidaConecta/conectatravel_react.git

# Acesse a pasta do projeto
cd conectatravel_react

# Instale as dependências
npm install

# Rode o projeto em ambiente de desenvolvimento
npm run dev
```

O projeto ficará disponível em `http://localhost:5173` (endereço padrão do Vite).

## 🧪 Como buildar para produção

```bash
npm run build
```

Os arquivos finais serão gerados na pasta `dist/`.
